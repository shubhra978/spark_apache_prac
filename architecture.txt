#Apache Spark notes

Its a application program which uses distributed architecture to manage and process data as per requirement.

Types of architecture:
Monolithic:
vertical scaling which is costly due to continious requriement of imporvement if large amount of data present.
limited availability at certain moments due to a dedicated machine approach.

Distributed:
consisting of multiple machine with same config in master and slave approach
task distributed into multiple machine as per requirement
horizontal scaling as machines can be added as requirement and availability is not limited
can handle  bigdata

narrow and wide transformation
The underlying structure of spark has a function of chunking. spark has a distributed architecture which do the tansformation in chunks.
For example: if i want to aggregate a table consisting of rows and columns, then before the transformation happens the table is divided into 128 mb chunks

Narrow transformation:
after the data is chunked it gets assigned to workers or nodes who will be working on the transformation but they will work parallelly without communicating,
exchanging the data then after the results are provided they will get merged into one result. Keep in mind it is being used for one input transformation.
example function: filter(),union()

Wide transformation:
When the data is chunked it gets shuffled before getting assigned to the workers or nodes who will be working on the transformation and provides the result.
Keep in mind it is being used for multi input transformation.
example function: groupby(), join(), distinct()
