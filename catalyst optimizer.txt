logical and physical plan
----------------------------
In driver node, once we write our code, spark session will create a  plan which is a unresolved logical plan.
  Next it will convert it into a resolved logical plan with help of catalog analysis.
  next it will be converted to a optimized logical plan.
Note that everything is being done by driver node before the handover to the worker nodes
Now with the help of the catalyst, driver node will select multiple physical plan to execute the logical plan which will be
  the cheapest physical  and the fastest one with help of cost model or CBO(cost based optimiser)

So if we are using resource which are unnecessary and redundant, spark will find the most optimised plan to execute our spark session
to see what are the jobs that are running( available in the personal hosted server version) we have to click on the jobs and view it.
  We can check for the duration, the steps involved and the storage or usage of data in it.
Also using this function '.explain()' we can check what is the physical plan spark is using for the session

Example:
== Physical Plan ==
LocalTableScan [id#11406L, gender#11410, age#11409L, salary#11411L]
