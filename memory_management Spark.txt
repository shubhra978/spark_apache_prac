spark.driver.memory
----------------------
JVM Heap:
the driver node consists of a JVM heap and a overhead layer. The work of JVM heap is to control operation which includes collect(), show(), memory management, task scheduling etc
COns: OOM issue happens if the data present in executor is more than allocated memory in driver when collect is used()
Overhead:
the overhead which is the 10% of the JVM heap atleast 384 mb has a role of non jvm processes, libraries, python funcitons

So whenever we use show functions it shows results of once of the executors and rest are still hidden
